# 📖 About

🚀 An elegant and interactive editorial portfolio website built using **React**, **Vite**, and **TailwindCSS**, designed to showcase the projects, skills, achievements, and technical journey, a passionate Computer Science Engineering student and aspiring Full Stack Developer.

The portfolio combines a modern UI with smooth animations and AI-powered functionality to deliver an engaging user experience.

# 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/navyaa27/portfolio.git
```

### Install Dependencies

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build Production

```bash
npm run build
```
